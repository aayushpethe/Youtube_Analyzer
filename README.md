# YouTube Video Analyzer

This project is a simple Agentic AI application that analyzes YouTube videos using an AI agent.

The user provides a YouTube video link, and the agent analyzes the video and generates a structured analysis report.

## Technologies Used

- Python
- Agno
- Groq
- YouTube Tools
- Streamlit
- python-dotenv

## How It Works

```text
YouTube Video Link
        ↓
   Streamlit UI
        ↓
    AI Agent
        ↓
   YouTube Tools
        ↓
   Groq LLM
        ↓
   Analysis Report
